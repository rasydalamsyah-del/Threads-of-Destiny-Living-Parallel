# ==========================================================
#  LOKASI YANG BISA DIJELAJAHI SAAT WAKTU BEBAS
#  Panduan: docs/DATA.md (bagian lokasi.txt)
#
#  [id]            = nama file latar (tanpa .jpg). Satu latar = satu lokasi.
#  nama            = nama tempat yang tampil
#  tempat          = desa / kota (aktivitas & orang mengikuti ini)
#  pintu           = tujuan | teks tombol | x, y | menit perjalanan        (pisahkan beberapa pintu dengan ;)
#                    tujuan "kos" = kamar kos yang sedang disewa
#  benda           = id_aktivitas | teks | x, y                           (ketuk → lakukan aktivitas itu)
#  orang           = id_karakter x, y, tinggi                              (posisi berdiri bila belum ada gambar adegan)
#  tidur           = ya → bisa tidur di sini (kasur)
#
#  x, y = posisi di gambar (0 = kiri/atas, 1 = kanan/bawah). Layar HP memotong ±10% kiri & kanan,
#  jadi taruh tanda di antara x 0.12 – 0.88.
#
#  orang = titik kaki orang itu di gambar latar (x, y) dan tingginya (bagian dari tinggi gambar).
#  Gambar latar + orang dibuat pemilik game: latar/<lokasi>__<id orang urut abjad>.jpg, mis. ruang_makan__ayah_ibu_laras.jpg.
#  Game memilih gambar itu otomatis sesuai siapa yang sedang ada (lihat docs/CERITA.md bagian 4).
#  Posisi orang harus sama di semua gambar lokasi itu. Bila gambarnya belum ada: latar kosong + tanda nama.
#  cadangan        = gambar pengganti selama latar/<id>.jpg belum ada
# ==========================================================
