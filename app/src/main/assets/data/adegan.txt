# ==========================================================
#  ADEGAN CERITA SAAT WAKTU BEBAS
#  Panduan: docs/DATA.md (bagian adegan.txt) · Alur: docs/CERITA.md
#
#  Adegan muncul sendiri saat pemain DATANG ke lokasi (pemicu = masuk) atau saat MENEMUI
#  seseorang (pemicu = orang), pada hari & jam tertentu, bila syaratnya terpenuhi.
#  Isinya ditulis di file naskah (folder naskah) mulai dari label, dan WAJIB diakhiri @kembali.
#  Adegan yang sudah dimainkan tercatat sebagai variabel adegan_<id> = 1 (dipakai syarat adegan berikutnya).
#
#  [id]
#  naskah = file naskah berisi adegannya, mis. adegan_prolog.txt
#  label  = (opsional) label awal adegan di file itu (bawaan = id)
#  judul  = keterangan singkat (untuk penulis)
#  pemicu = masuk / orang   (bawaan: orang bila ada kolom "orang", selain itu masuk)
#  lokasi = lokasi tempat adegan terjadi (wajib untuk masuk; untuk orang = hanya bila ditemui di sini)
#  orang  = id karakter yang ditemui (pemicu orang)
#  waktu  = (opsional) hari & jam, mis. senin-sabtu 15:00-17:30, minggu 08:00-11:00
#  syarat = (opsional) mis. desa_bab == 2 && adegan_b2_sekar_kenalan == 1
#           variabel tanggal: tgl = bulan*100 + tanggal (627 = 27 Juni), hari_ke, jam_menit
#  sekali = ya (bawaan) / tidak
#  Urutan di file = prioritas (yang di atas dicek lebih dulu).
# ==========================================================
