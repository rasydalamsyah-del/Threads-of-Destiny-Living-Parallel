# ==========================================================
#  PESAN CHAT DI HP (dan pilihan balasannya)
#  Panduan lengkap: docs/DATA.md
#
#  Setiap pesan punya 2 pilihan balasan yang NYAMBUNG dengan isi pesannya,
#  dan jawaban si pengirim untuk masing-masing balasan.
#
#  [id]
#  dari          = id karakter (* = siapa saja; dipakai pesan dari sistem, mis. janji batal)
#  jenis         = cerita  → dikirim dari naskah (@hp pesan ...). "isi" harus sama persis dengan teks di naskah.
#                  acak    → kadang dikirim sendiri oleh karakter (maks. 2 pesan per hari dari semua karakter)
#                  sistem  → dikirim oleh game (janji batal, dll.)
#  isi           = isi pesan masuk
#  hangat        = balasan hangat pemain (Cinta +3, sekali sehari per orang)
#  balas_hangat  = jawaban pengirim atas balasan hangat
#  singkat       = balasan singkat pemain (Cinta +1)
#  balas_singkat = jawaban pengirim atas balasan singkat
#  syarat        = (opsional, untuk acak) contoh: lokasi == kota
# ==========================================================
