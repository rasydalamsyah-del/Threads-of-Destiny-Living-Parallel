# ==========================================================
#  OBROLAN SAAT MENEMUI SESEORANG
#  Panduan lengkap: docs/DATA.md
#
#  Setiap karakter punya obrolannya sendiri, sesuai sifat, profil, dan alur cerita.
#  Menu "💬 Ngobrol" berisi:
#    😊 Ngobrol santai          (jenis = santai)  → boleh diulang; efek penuh sekali per hari
#    🔍 Kenali lebih dalam       (jenis = kenal)   → bertanya tentang dirinya; membuka info profil.
#                                                   Tidak muncul bila info itu sudah kamu ketahui.
#    ❓ pertanyaan khusus        (jenis = khusus)  → tampil langsung di menu bila "syarat"-nya terpenuhi
#  Satu pertemuan: paling banyak 2 kali ngobrol.
#
#  [id]
#  karakter = id karakter
#  jenis    = santai / kenal / khusus
#  judul    = teks tombol
#  kamu     = kalimat yang diucapkan pemain
#  jawab    = jawaban karakter. Beberapa kalimat dipisah " // ". Diawali "*" = narasi.
#  efek     = efek bila berhasil (cinta, percaya, atau variabel lain, mis. petunjuk_sahabat +1)
#  topik    = (santai) id topik dari topik.txt → tercatat di "Suka"/"Tidak suka" halaman Karakter
#  akrab    = Cinta/Keakraban minimal agar ia mau menjawab (bawaan 0)
#  percaya  = Kepercayaan minimal (bawaan 0)
#  tolak    = jawaban bila belum cukup akrab/percaya
#  ungkap   = info profil yang terbuka: hobi, kegemaran, pelajaran, keahlian, cita_cita, kisah_1/2/3
#  ungkap_lain = info profil karakter lain, contoh: sahabat kisah_2
#  syarat   = (opsional) contoh: jalur == kerja && kerja_aktif == 0
#  sekali   = ya → hanya bisa ditanyakan sekali (kenal & khusus otomatis sekali)
# ==========================================================
